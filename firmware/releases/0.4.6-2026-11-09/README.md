# 0.4.6：每分钟轻睡眠、BOOT按需配置

2026-11-09，已通过校验上传和认证API核验。CPU 80MHz，平时停止Wi-Fi及网页进入Light-sleep，保留RAM前帧和屏幕状态；每分钟醒来联网更新，再休眠。短按BOOT开启10分钟配置，重启后有90秒窗口；网页可“保持配置10分钟”或“立即省电”。原分区、网络、天气、60秒行情与配色保留。

用户确认测试中按过BOOT，同时观察到配置窗口。后续纯自动记录休眠计数3、4、5，配置剩余均0，单次实际休眠57.437秒；联网与局刷继续，全刷计数保持1，天气计数保持2，没有每次重连重复抓天气，原配置逐项不变。已退出配置并停止网络轮询。当前休市，使用真实收盘行情；未宣称开盘红色动态行情或长期休眠稳定性已全部验证。

本次Mac会话在轻睡眠后USB串口日志未恢复，初次串口观测无法完成；后续用独立认证API快照与计数核验。短暂醒来时可能正在绘图，末尾读回先保持配置再核对，完成后退出。该限制不等于设备重启或停止运行。后续USB烧录建议先按RESET进入启动窗口；BOOT主要用于网页配置，不保证恢复USB日志。0.4.5恢复固件保留，不整片擦除。

编译1289837字节，原应用上限1310720字节；静态RAM88928字节。只对C++和链接启用LTO以保留原分区，字体和波形数据未变。必须使用source.zip中的`uv run tools/build_firmware.py`构建；不能对现有SDK的C文件一起启用LTO，会触发弱回溯钩子链接错误。FQBN仍为esp32:esp32:esp32s3:CDCOnBoot=cdc，增量缓存目录沿用build/low-power-045，实际版本由校验值及启动身份核对。

用户原报告USB／5V整机50mA，0.4.5报告约40mA；0.4.6休眠电流仍待外部读表，不用软件sleep标志推算mA。配置窗口仍是正常工作电流，读表应在退出配置、本轮刷新结束后的休眠阶段。

source.zip含源码、生成器、测试、构建器、操作说明和许可证；manifest.json记录SHA-256，SHA256SUMS覆盖本目录。凭据不含于归档。

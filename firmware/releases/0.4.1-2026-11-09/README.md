# 0.4.1：股票红色局刷、红色名称与状态、等宽数字

2026-11-09，已通过Arduino CLI编译、校验烧录，并以真实长江电力行情在设备运行。

- 保留原横屏大图表；股票名称和状态改为红色，上涨报价红色，下跌报价黑色，价格线黑色、均价线红色。
- 新增红色局刷模式；仅时间或黑白内容改变时快速局刷。红黑两步行情更新本次实测17491ms，时间窗口938ms；股票页每10分钟维护全刷。
- 股票相关16/18px数字为Menlo Regular，48px现价为Menlo Bold，原生单色字模。每个字号内数字占位统一，避免4的字形显窄；中文保持。
- 字模无损压缩，程序1307245字节，沿用原1310720字节应用分区，未改分区、未整片擦除。网络、天气、股票、交易时段优先及卡片轮播配置保留，只将刷新方式改为color_partial。
- 两个已知原厂波形以完整指纹校验，未知波形使用全刷；保留当前原厂电压／结束参数，不写OTP。黑白快刷、三色全刷选项保留。

逻辑回归覆盖全部颜色转换、相邻静态像素、两种原厂波形及损坏输入拒绝；交易日程、卡片和农历测试通过。写入Hash校验、启动身份、真实行情、关闭串口后主循环前进和配置保留均已记录。最终字形、红色观感和长期残影由实屏确认；电气通过不等于全部物理转换场景验证。

`source.zip`含源码、构建工具、测试及项目约束；`manifest.json`记录二进制及源码SHA-256，`SHA256SUMS`覆盖本归档。凭据仅在设备NVS和忽略的local目录，不包含于归档。

## 编译与上传

FQBN：`esp32:esp32:esp32s3:CDCOnBoot=cdc`，Arduino ESP32 Core 3.3.11，现有4MB默认分区。烧录前确认硬件端口；复用本目录构建产物，执行Arduino CLI upload --verify，不整片擦除。源码入口为解压后的`firmware/epaper_dashboard/epaper_dashboard.ino`。

## 回退

0.3.2和已接受的红色单次实验仍独立保留。回退0.3.2前，先在当前网页把刷新方式切为黑白快刷或三色全刷并保存，再校验上传旧固件；旧版不认识color_partial，不能仅刷旧版而保留这个新模式字符串。Wi-Fi和和风凭据无需重录，不执行整片擦除。

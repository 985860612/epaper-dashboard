# 0.4.5：在线省电

2026-11-09。保留网页和每分钟真实行情更新，CPU设为80MHz，Wi-Fi设为WIFI_PS_MAX_MODEM，空闲前台轮询设为20ms。20ms yield不是Light-sleep；未启用Deep-sleep，不改屏幕波形、字模或配色。

原报告50mA来自用户USB／5V整机读数，约0.25W。优化后电流需要用户在相同条件测量；固件没有电流传感器，不能用CPU频率、API响应或休眠标志宣称实际mA已降低。

新模式可能增加Wi-Fi收包等待，具体由路由器信标和监听周期决定。屏幕刷新后已有模拟电源关闭命令；未额外重置屏幕，保留局刷前帧状态。未改分区或NVS配置，不整片擦除。

实际80MHz、Wi-Fi模式2、启动全刷及关闭串口后的行情/API观测记录随本目录归档。细节见source.zip中的docs/power-optimization.md；最终电流改善待外部电流表确认。0.4.4固件单独保留，可保留当前配置回退。

FQBN：esp32:esp32:esp32s3:CDCOnBoot=cdc。编译1307449字节，原应用上限1310720字节，静态RAM88728字节。source.zip包含源码、生成器、测试和许可证，不包含凭据；manifest.json与SHA256SUMS可核对。

# 0.4.2：统一小字笔画观感

2026-11-09，已编译、校验烧录并完成初次全刷。用户反馈0.4.1文字粗细不一；对照实际固件字模可复现Menlo小字号斜杠0与1偏重，等宽并未解决字重差异。

16/18px ASCII改为Andale Mono Regular，按原生尺寸单色生成，不拉伸、不加粗小字；去掉斜杠0，采用该字体自身的点心0。16/18px数字1中段主竖笔逐行验证为1像素，各字号内数字占位一致。所有既有中文和26/48/80/104/164px大字字模逐字节保持不变；字形转角及笔画交点不以机械细化破坏结构。

红色名称和交易状态、红黑两步行情更新、分钟时间局刷、十分钟维护全刷继续沿用。仅修改字体生成器、生成字模与版本号，未改刷新波形。首次全刷清除旧残影，实测28022ms；本次识别A4原厂配置。关闭串口后主循环前进、API无显示错误，配置与0.4.1逐项相同。最终小字视觉效果等待用户实屏确认。

编译1306925字节，原应用分区上限1310720字节；静态RAM88720字节。保留分区、Wi-Fi及和风凭据，不整片擦除。旧0.4.1归档保留。本次复用增量构建缓存目录build/stock-red-041，产物与启动身份均为0.4.2，以manifest与应用SHA-256核验版本。

- `small-font-comparison.png`直接解码两版固件字模对比，放大仅便于查看像素。
- `source.zip`包含源码、字模生成器、测试和许可证，不包含凭据或系统字体文件。
- `manifest.json`记录源码和固件SHA-256，`SHA256SUMS`覆盖本目录文件。

FQBN仍为`esp32:esp32:esp32s3:CDCOnBoot=cdc`。可用Arduino CLI upload --verify复用本目录上传，先确认实际硬件端口。不整片擦除。回退0.4.1可保留当前配置；若回退0.3.2，先在当前网页切回黑白快刷或三色全刷并保存，因为旧版不识别color_partial字符串。

# 0.1.7 中文小字字形与基线调整

正文16px、Header18px的中文改为PingFang SC Regular（苹方简体常规体）。旧正文使用Heiti TC默认字面，并逐字按笔画顶端对齐；新版使用统一基线，简单横画与标点保留正常位置。按最终尺寸生成1位实心字模，没有扩笔加粗或抖动。

英文数字、股票名称26px、现价48px、时钟80px字模逐字节保持不变；布局与图线范围不变。少数超过16px字格的非汉字宽符号在生成阶段使用合适的原生字号，普通中文保持16px。系统字体文件不随项目分发。

验证：4533个字符全部保留，数字字模和大字号字模相同，简单横画基线检查通过；交易时间边界测试通过。编译应用1289597字节，静态RAM88192字节，保留4MB默认分区；分区表与0.1.6逐字节相同。

上传哈希校验通过。设备报告版本0.1.7，时间页模式clock保留；首帧全刷20644ms，刷新就绪BUSY=0，displayError为空。和风天气有效，阿里云SNTP回调为2026-11-08 17:38:24，间隔3600秒。

局刷仍关闭，三色全刷与现有网络设置保持；本屏原生灰度尚未验证。本版实际字形观感待用户确认。

串口监视器关闭后，2026-11-08 17:40:50观察到第二次定时全刷完成：fullRefreshCount=2、耗时20563ms、显示错误为空，确认主循环持续更新。见periodic-refresh-check.json。

clock-preview-400x300.png为像素预览；clock-comparison-800x300.png左侧为0.1.6，右侧为0.1.7，均按400×300生成，没有模拟设备灰度。预览使用反馈照片中的17:29与8度作为静态排版样本，设备使用实际时间和天气。

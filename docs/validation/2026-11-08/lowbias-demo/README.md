# 低偏置局刷首轮与重触发异常

用户已确认227字节长表可局刷，但反馈浅红背景。本次在已确认基线上试验参考波形的08h低公共偏置（-0.2V），其余波形、字体、门极/源极电压与结束参数不变；开始先正常全刷清理旧残留。

`epaper-dashboard-0.1.9-lowbias`在首次局刷前读回并保存原生50h偏置（-2.0V），每次局刷前写08h，BUSY结束后恢复50h。应用1286005字节，上传校验通过，首轮6次931–945ms，无显示错误，全刷计数保持1；串口关闭后从2次继续到6次。源代码、编译/上传日志、窗口串口和API观察均在本目录。

用户随后要求重新触发。20:01:10设备接收partial_probe，串口记录WATCH_START，但随后窗口成功计数停留6、全刷计数变为2，partialStatus为unsupported_or_timeout，末次记录127ms。这轮没有完成6次局刷。其具体失败阶段没有被当时已关闭的串口记录到，不能把127ms直接解释为实际显示阶段或8秒BUSY超时。用户追问是否触发时，已如实说明指令收到但本轮未正常完成。

该版本首组通过并不代表暂停重触发可靠，背景颜色改善亦未得到用户确认；没有发布为稳定固件。已转入第二版对比：黑白会话保持低偏置，到全刷时再恢复三色参数，并在每次更新入口重新初始化SPI读状态，补充BUSY回调计数与控制器状态日志。第二版结果另存，不覆盖本目录证据。

设备NVS仍保存原配置，实验模式只覆盖RAM；分区未改，无OTP编程。已确认可局刷的上一版完整备份在相邻epaperdrive-lut目录。SHA256SUMS用于核验。

验证包含已有交易时段/午休压缩/跨年日历/VWAP测试，以及直接提取生产constexpr回放函数的性质检查：0–245点均不越界、进度单调、足够长的数据每步前进、末步覆盖全部点。完整历史数据比对、串口、API过程与摘要分别保留；SHA256SUMS用于核验，不含私有访问配置。

模式只临时覆盖RAM，不保存演示到NVS。完成后保持最后一帧，partial_probe可从头再播放12步；partial_stop停止。stock_replay重新抓取并准备快照，待数据有效后切换。首次全刷若BUSY不就绪或耗时异常过短，会停止后续绘制并报告初始化失败。需要恢复时间测试时，已确认时钟局刷固件仍在相邻epaperdrive-lut目录。

当前快速动态路径只写黑白数据，红色RAM用于旧帧同步，红色变化会改走全刷；静态红标记可保留。红色快速局刷尚未适配验证，不从“三色屏”名称推断能力。上游的[三色屏黑白快刷示例](https://github.com/ZinggJM/GxEPD2/blob/master/examples/GxEPD2x_FastBlackWhiteOnColor/GxEPD2x_FastBlackWhiteOnColor.ino)也区分静态红色与黑白动态区域。

## 对中间变灰的排查

代码中，中间40×40区域写入`R/BW=10`，与[SSD1683手册](https://files.seeedstudio.com/wiki/Other_Display/42-epaper/IC%20Driver%20SSD1683%20Datasheet.PDF)第13页的三色LUTR映射一致；上游GxEPD2写红平面的反相逻辑也支持该极性。坐标和颜色位的源码审查没有发现写反。但本次没有回读图像RAM或测量驱动电压，不能声称已完全排除传输、升压或模式问题。

按本次真实读回波形，使用手册第14—17页的RP/SR/TP规则独立计算：

| 项目 | 原生完整三色波形 | 首组候选 |
| --- | --- | --- |
| 全部阶段帧数 | 994帧 | 58帧 |
| 按50Hz计算的名义驱动 | 19.88秒 | 1.16秒 |
| RED表选择VSH2的累计帧数 | 340帧 | 34帧 |
| 上述电平的累计时间 | 6.8秒 | 0.68秒 |
| 实际BUSY更新耗时 | 20.653秒 | 1.392秒 |

原生Group 4/5/6的RED表各有34帧VSH2阶段，分别重复3/4/3次；首组只保留Group 4的一次，同时删去了其他预处理阶段。因此不是简单把原生红色局刷加速，而是把形成红色的驱动过程裁成了很短的一段。**优先假设是驱动时长及预处理／黑红粒子分离不足，尚未通过对照实验定位唯一原因。** 中间变灰与该假设相符，但不能推断为屏幕损坏，也不能推断只延长时间就一定成功。

[三色电子纸黑红粒子分离研究](https://www.mdpi.com/1996-1944/15/7/2555)说明，形成高纯度红色依赖粒子状态准备、黑红分离和红色驱动时序。该论文使用其他实验面板，其电压和时长不可直接套到当前HINK。

后续最小变量对照：先保留同一原生Group 4的原始3次重复，不改变电压和各脉冲长度。其名义驱动174帧/3.48秒，VSH2累计102帧/2.04秒。这只是下一轮候选，**本次尚未实现或烧录**。如果仍灰，应继续比较原生阶段衔接／粒子准备，而不是盲目提高电压。增加时长也会延长窗口外的公共偏置暴露，需要重新观察静态背景和红色参考块。

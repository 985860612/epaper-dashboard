# 股票红色局刷与等宽数字

2026-11-09。用户确认红色增强擦除实验可接受后要求股票页增加红色，又根据实屏照片要求股票名称、交易状态变红，以及优化数字4的观感。

## 页面

保留横屏400×300和原图表区域。名称、交易状态用红色；上涨现价、涨额和涨幅用红色，下跌保持黑色；分时价格线黑色、成交均价线红色、昨收虚线黑色。黑白快刷模式保留，其名称和状态仍为黑色。

原数字已为固定占位，主要差异来自字形墨迹。股票相关16/18px数字改用Menlo Regular，大号价格48px使用Menlo Bold；原生单色字模，无缩放、无灰度抖动、不加粗小字。三个字号内0—9占位分别为10、11、29px。已有中文及非数字符号之外的字形逐字节比较保持不变；字号和图表边界保留。

## 两步更新

1. 完整刷新后两次读取原厂233字节波形，只允许本屏已捕获的A8/A4完整指纹。缓存增强擦除候选，未知配置不激活定制红色波形。
2. 比较前后红色平面：未变像素使用00保持，移除红色使用01擦白，新增红色使用11成红。写候选227字节后读回校验，保留原厂6字节电压／结束参数，不写OTP。
3. 红色完成后重建黑白前帧RAM。红色处理过的像素以白底作为黑白差分起点，再补画黑白，避免擦除新红色或遗漏红转黑。
4. 仅时间或黑白变化时沿用快速窗口刷新；股票页每10分钟维护全刷，卡片轮换、布局变化和未知波形回退全刷。异常后关闭局刷并准备全刷恢复，不自动反复重试失败波形。

网页新增`color_partial`；原`bw_partial`和`color_full`保留。抓取间隔下限分别为30/15/120秒，已有120秒不变。保留交易时段自动股票、非交易卡片轮播及固定卡片设置。设备不依赖串口监视器。

- 交易时间、午休压缩、成交均价、卡片轮播与1096天农历数据回归通过。

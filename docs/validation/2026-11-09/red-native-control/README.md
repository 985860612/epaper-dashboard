# 第四组：完整原生波形与原始写入路径对照

2026-11-09，第三组编码对齐后仍深灰，用户要求继续。此次明确采用完整全刷对照，以检查原始RAM写入／C7激活路径是否能在完整原生波形下正确形成红色；**不是局刷成功或快刷方案**。

## 方法与实测

- GxEPD2原生F7全刷建立基准：左红、中白、右红。基准20649ms，BUSY正常结束。
- 原屏233字节波形连续读回一致，并与前三组逐字节一致。
- 227字节主波形原样复制，无保持类改写、阶段裁剪、重复次数调整或电压修改；写入后主表读回匹配，原生6字节结束／电压参数相同。
- 使用与GxEPD2相同的逻辑颜色缓存和实际写入极性（BW原样、颜色反相），直接写入完整目标图：左白、中红、右红、白底黑色文字边框。常规三色数据代替前几组的保持掩码。
- 以同一Mode 1/C7命令只激活一次，不加载OTP覆盖已核验的表；994帧，名义驱动19880ms，实际20402ms。观察到BUSY拉高后正常回低，无超时，随后进入休眠保持最终画面。

版本`red-unaltered-native-control`，Sketch341942字节、静态RAM84696字节，应用SHA-256 `734786dff9dcec065082cf00d81bd00f070e981b859434a16d0b136d03080436`。整表无损复制、994帧计算、错误表长／电压／帧率／异常阶段的拒绝和BW/RAM三色极性离线检查通过。分区与0.3.2二进制一致，全部上传Hash校验通过。

已向用户请求确认最终中间和右侧是否均红、左边是否白。留出观察机会后恢复生产固件，当前**尚未收到本次完整对照的实屏颜色反馈**，不能把20402ms及BUSY完成写成红色显示成功。

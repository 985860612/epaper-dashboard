# 0.4.6 每分钟轻睡眠验证

用户选择省电优先、每分钟唤醒更新、网页按需开启，确认有BOOT按钮。保留原400×300屏幕及引脚、原4MB分区、NVS网络/天气/股票配置和现有字模与波形。本文记录代码与电气证据，不替代外部整机电流表测量。

离线检查已通过分钟微秒边界、配置窗口到期、millis回绕、跨分钟刷新，既有交易日程/均价/卡片与农历边界回归通过；网页gzip解码与源码相同，JavaScript语法通过。字体和红色波形头与0.4.5逐字节比较一致。

普通编译超出原应用上限；全C/C++ LTO触发现有SDK的C弱回溯钩子跨地址区链接错误。最终只对C++和链接启用LTO，C保留原编译方式，成功控制在1289837字节，静态RAM88928字节。由tools/build_firmware.py复现，不修改全局SDK。

实机步骤：校验上传，读取0.4.6身份和初次全刷，验证配置窗口延长、未认证电源接口401、关闭窗口后自动唤醒两轮；比较休眠前后全刷/局刷/联网计数及配置。测试后恢复省电循环，再由用户物理短按BOOT验证配置与读取USB／5V整机电流。

实机已校验上传0.4.6，初次全刷完成。用户明确确认测试期间按过BOOT，并观察到配置窗口。随后纯自动API快照记录休眠计数3、4、5，配置剩余均0；最长单次实际休眠57.437秒，联网取样与局刷继续，全刷计数保持1，天气抓取计数保持2，没有每次重连重复抓天气。原配置逐项不变。因Mac USB串口日志在轻睡眠后未恢复，改用认证API计数；短暂唤醒窗口需先保持配置才能完成末尾读回，不能把未捕捉到空闲响应当作未休眠。已退出配置并停止网络轮询。日志和完整核验结果归入发布目录；整机电流读数仍待用户外部测量，不用软件计数冒充mA。当前为休市时段，行情来自真实已收盘数据；不宣称已验证开盘红色变价或长期休眠稳定性。

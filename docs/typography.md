唯一规格为tools/typography.json；生成器校验真实字体名与0—9步进。数字同一档步进一致，字母保持比例。typography.h统一测量、基线、UTF-8省略及绘制。所有页面调用语义角色；不再自行选字体或缩放。

18px基础字库保留GB2312一级汉字及界面额外用字，共3769个汉字；整体3871字符。20/24px采用界面子集，动态地名/股票名含该字号未打包字符时整段回退同字体18px，保持基线并按像素宽度省略，不逐字混字号。未收录罕见字显示问号。为保留原应用分区，省去旧字库中676个未在界面使用的非汉字符号；需要更多外文/符号时应扩充规格并重新检查容量。源文件和校验值见assets/fonts元数据；方正原字体只在被忽略的local/fonts/，不随源码ZIP分发。

字形记录包含真实宽高、步进和基线偏移，512字符一块；字符索引采用差分编码。构建端Zopfli生成标准zlib流，设备仍用现有miniz解压；所有字号共用原32KB缓存，最大块23069字节，避免大字反复申请临时内存。规格与完整常用字符清单在tools/内。重建用uv run tools/build_fonts.py；直接编译已生成字模不需原字体。

外边距20px；数值右对齐、日期/主时间居中。股票涨额与涨幅用斜线合为一行，主图为376×120（x20—396、y132—252），上下刻度仅保留价格，右对齐396，上方刻度在昨收虚线下方动态避让曲线，下方刻度基线296，均价线移除，价格线按昨收价分色（高于红色、低于或等于黑色，跨越时在交点分段），股票名和交易状态黑色、现价红色；涨幅上涨红色、下跌/持平黑色。总览的次要报价保持黑色以沿用黑白快刷。图表极大数值可减少刻度小数或使用k/M，现价本身仍保留完整两位小数。

layout_regions.h统一各页局刷窗口，与文字布局一同验证；窗口按8像素对齐。月历有顶部与侧栏两个时间，两处一起局刷。未校时/交易日历过期/缓存提示也按独立空间排版。波形、电压、GPIO、时间及行情更新策略、轮播与每分钟轻睡眠保持。

uv run tools/check_typography.py从实际C++页面头与生成字模渲染预览，验证全部字形解码、步进、文字越界/重叠、时间和天气改动像素的局刷覆盖；覆盖2026—2028所有月份、长城市/股票名、极端数值、历史与缺失数据、无效日历以及坏字库恢复。测试夹具预览非实时数据，非设备照片。tools/preview_font_test.py兼容入口会生成同一套检查。

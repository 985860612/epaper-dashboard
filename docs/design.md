# 设计与数据规则

2026-11-08，用户确认横屏简约时间天气与股票版式，明确股票为长江电力，天气为北京顺义；要求从集合竞价起展示股票、正式开盘显示参考图中的分时价格线和均价线，Wi-Fi独立运行，网页配置，复用旧和风Key，并使用阿里云时间服务器每小时校时。

## 显示与调度

| 北京时间（交易日） | 自动模式 |
| --- | --- |
| 09:15–09:25 | 股票、集合竞价价格与状态 |
| 09:25–09:30 | 股票、待开盘 |
| 09:30–11:30 | 股票、当日分时 |
| 11:30–13:00 | 时间天气 |
| 13:00–14:57 | 股票、当日分时 |
| 14:57–15:00 | 股票、收盘竞价状态及行情源提供的当日分时 |
| 其余时段、周末与公告休市日 | 时间天气 |

时间区间右端不包含。分时横轴压缩午间，09:30为0、11:30/13:00为120、15:00为240；未来时段留白。集合竞价价格不混入正式交易分时。换日后仅接受行情日期匹配的数据，避免将上一交易日图线当作今日走势。

文字与数字使用最终字号的1位字模，分割线和折线使用GFX原生整数坐标；界面不做整图抖动。黑色表示价格线，红色表示均价，虚线表示昨收。现价上涨用红色及正号，下跌用黑色及负号。

字体经过轮廓加粗与像素字实验后，用户确认像素版清晰，但要求小字常规字重、大字采用生成字模、Header稍大。当前使用正文16px、Header18px、名称26px、价格48px与时钟80px的原生字模；移除底部时间刻度、行情日期和页码，将折线区域扩大为`x54..334、y160..284`。当前[三色预览](../assets/generated-layout/stock-color-400x300.png)与[黑白研究预览](../assets/generated-layout/stock-fast-400x300.png)用于检查布局，实屏验证另记。

## 数据源

和风凭据由用户授权从既有`qweather-hourly/.env`读取，仅导入新设备NVS，不修改源项目。实时天气`/v7/weather/now`，三日预报`/v7/weather/3d`取当日高低温，城市搜索`/geo/v2/city/lookup`。顺义LocationID由实际GeoAPI查询得到`101010400`。支持gzip并保持TLS证书及主机名校验；公共CA见`trust_roots.h`，不使用`setInsecure`。

腾讯财经网页分时接口`https://web.ifzq.gtimg.cn/appstock/app/minute/query?code=sh600900`提供报价及分钟数据。该接口未承诺稳定的开发者协议，解析失败显式报错；如接口变更需更新适配，不把空值补为实时行情。分钟行实测格式为`HHMM price cumulativeVolumeHands cumulativeAmountYuan`，均价按累计成交额除以累计手数乘100后的股数计算，不使用价格的简单平均。零成交量时均价缺失，不补造。网页明确标注来源。

## 交易日历与时间

2026休市安排来自[上交所公告](https://www.sse.com.cn/disclosure/announcement/general/c/c_20251222_10802507.shtml)，预置非周末休市日期；周末始终关闭。年份和日期可在网页更新，日历年份不匹配则自动股票模式关闭并提示更新。

交易时段依据[上交所交易规则](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20260424_10816482.shtml)。和风接口依据[城市搜索](https://dev.qweather.com/docs/api/geoapi/city-lookup/)、[天气接口](https://dev.qweather.com/docs/api/weather/)、[API认证](https://dev.qweather.com/docs/configuration/authentication/)。

阿里云SNTP在联网后启动，间隔明确设置为3600000毫秒，由系统任务后台执行。网页显示实际同步回调时间；“已配置每小时同步”与“观察到完整一小时周期”应分开验证。网络不可用时SNTP重试不会使伪造时间变成成功校时。

## 配置边界

局域网页和AP网页均需管理密码；浏览器已有Key和密码字段只显示“已配置”，不回传明文。JSON配置请求需正确Content-Type且受Basic认证保护，未启用跨域。配置持久化到独立NVS空间，仅连接Wi-Fi、读取API和刷新屏幕；不执行股票交易，也不配置远端服务器。
